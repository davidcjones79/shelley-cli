Help & Documentation

What is the Shelley Coordinator?

The Coordinator manages a pool of worker VMs that execute coding tasks in parallel. Each worker runs Shelley (the AI coding agent) to complete tasks like fixing bugs, adding features, or refactoring code.

Getting Started

  1. Start the Coordinator — Click the green "Start" button
  2. Scale Workers — Set the number of worker VMs (1-10)
  3. Add Tasks — Enter prompts describing what you want done
  4. Monitor Progress — Watch tasks move from Queued → Running → Completed

Example Task Prompts

"Fix the failing tests in auth_test.go"

"Add input validation to the signup form"

"Add a /health endpoint that returns JSON with uptime"

"Refactor handlers.go - split into separate files by resource"

"Add TypeScript types to the API client"

"Find and fix SQL injection vulnerabilities"

Task Statuses

QUEUED — Waiting for an available worker

RUNNING — Being executed by a worker

COMPLETED — Successfully finished

FAILED — Encountered an error

Worker States

Idle — Ready to accept tasks

Busy — Currently executing a task

Starting — VM is being provisioned

API Access

You can also interact with the coordinator programmatically:

# Add a task

curl -X POST /api/enqueue \
  -H "X-Coordinator-Token: $TOKEN" \
  -d '{"prompt": "Fix the bug"}'

# Check stats

curl -H "X-Coordinator-Token: $TOKEN" /api/stats
